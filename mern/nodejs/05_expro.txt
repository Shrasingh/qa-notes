        2.Middleware Patterns (VERY IMPORTANT)
💡       Middleware = Pipeline
         app.use(authMiddleware);
         app.use(loggingMiddleware);
         app.use(rateLimiter);
         Types:
         Global middleware
         Route-specific middleware
         Error middleware
         Example
        function auth(req, res, next) {
            if (!req.headers.token) {
              return res.status(401).send("Unauthorized");
            }
            next(); //next() = “pass control to the next middleware/function in the chain”
        }
        next() is a function used in Express middleware to pass control to the next middleware in the request-response cycle. If not called, the request will hang.
        “Express internally maintains a middleware stack, and next() moves execution to the next function in that stack.”
      💡 Real-life analogy:  Airport security:   ID check → auth middleware
                                                 Bag scan → validation middleware
                                                 Boarding → controller
    Interview Questions

 Q2:How does middleware work internally in Express?
    “Express middleware works as a chain of functions executed sequentially.”
     Explanation -Each middleware gets (req, res, next)
    Calls next() → passes control
    If next(err) → jumps to error handler
    Internally:
    Express maintains a stack (array) of middleware
    Iterates one by one
    Analogy: Assembly line in factory
     What if next() is not called?
        Request hangs, The request never moves to the next middleware
        No response is sent, The client (browser/app) keeps waiting
        Eventually → request hangs / times out
    
    What if next(err) is called? 
       Skips normal middleware → error middleware

    const rateLimit = {}; // it is in memory object It stores request counts per IP 
         {"192.168.1.1": 45,"10.0.0.2": 101}
    function limiter(req, res, next) {
      const ip = req.ip;
      rateLimit[ip] = (rateLimit[ip] || 0) + 1;
      if (rateLimit[ip] > 100) {
       return res.status(429).send("Too many requests");
       }
       next();
      }
